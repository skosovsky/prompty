Combination reconciliation includes only policies selected by standalone checks. All participating advisory intent is omitted first; reevaluated required conflicts fail without dispatch. Removing one optional policy does not discard independent controls or force a second request. Static diagnostics use source paths, not values. Implicit intent remains in diagnostics even though no SDK block field is generated.

Provider/account authorization, credentials, transport, storage and reuse policy remain host-owned. Request-control mapping does not maintain a cache store, generate content-derived reuse keys, upload resources or schedule deletion/refresh. Gemini resource operations are separately explicit host invocations, not hidden effects of a request hint. Host redaction applies to arbitrary prompt/control values in logging or capture; cache diagnostics themselves contain no such values. Request fixtures do not certify all live model/account/resource timeout semantics; resource fixtures and final paired acceptance remain separately required.
