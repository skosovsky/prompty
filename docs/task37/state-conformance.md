Missing state-mapping ports are rejected by checked preparation; raw OpenAI/Ollama translators also explicitly reject envelopes. Profiles cannot add a state codec implementation. Model-family sharing is only the caller-declared scope comparison, not access to another account or destination. Transport configuration and provider capability knowledge remain host-owned.

The fresh targeted race reconciliation runs root/workspace packages and all four nested provider modules explicitly; root `./...` alone does not include nested modules. Full all-module lint/test gates remain the general acceptance checks. Additional native transports, remote operations/resources and lower-guarantee forced-tool output still require their separate demand decisions.
