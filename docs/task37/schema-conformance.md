# Schema mapping and validation evidence

These are implemented mapping guarantees and local conformance fixtures, not certification of a live endpoint/account/model. Checked profile knowledge and actual mapper availability are independent gates. No provider catalog, implicit remote reference fetch or automatic repair/replay is introduced.

The [OpenAI structured-output specification](https://developers.openai.com/api/docs/guides/structured-outputs) requires closed objects and documents recursive schemas. This is a reference for mapping decisions, not live fixture evidence or a declaration that every JSON Schema keyword works at every destination.

## Universal checked enforcement

`CompileProviderSchema` compiles an isolated original before mapping, enforces explicit change permissions, compiles the translation, and retains exact-byte digests, destination/role/name/dialect and an immutable original validator. The validator is a trusted injected compiler, not a provider capability declaration. The bundled implementation explicitly supports its declared dialects and supplied reference resources; annotations do not become application business assertions.

`adapter/tool_schema_lowering_test.go` uses an explicitly synthetic mapper that drops minimum/required with a reported ledger. Across sync/buffered/native, invalid arguments retain known tool content/outcome/usage and associated digests but fail original validation; a valid positive control succeeds. Every path dispatches once, source execution wire remains unchanged, streams have one terminal and correct final status. A typed registry accepting Go integers cannot let below-minimum/missing/null arguments reach a handler. This is universal port enforcement, not a claim that an existing provider offers those lowering transforms.

Source compilation/alias fixtures are in `schema_compile_test.go`; per-definition clone/wire/YAML/helper selection and unavailable-validation zero-dispatch fixtures are in `schema_dialect_test.go` and corresponding adapter/parser fixtures. Output required-nullable integration is separately proven by actual OpenAI SDK sync/native fixtures, not inferred from the synthetic tool mapper.

`schema_children_test.go` also covers schema-valued additional/unevaluated properties/items with exact source pointers; property-dependency name arrays/default/examples/content annotations remain data rather than generation-target schema locations. `schema_reference_test.go` proves optional local-ref wrapping, exact numeric enum SDK serialization and the difference between original missing/non-null and translated required-nullable. These compiler/serialization fixtures do not assert live acceptance of each applicator.

`schema_reference_transport_test.go` supplies a working HTTP schema endpoint and verifies zero requests for missing, explicitly supplied and transitively missing references, including value validation. Missing resources fail before mapper invocation; an explicit local resource validates minimum without fetching. Caller-supplied validator resources are not an implicit SDK/provider resource-upload mechanism.

`schema_compilation_error_test.go` exercises actual bundled engine metaschema errors: escaped property names, array indices, a genuinely invalid root, explicit resource identity, sorted multiple failures and source dialect mismatch. Output/tool roles fail before mapper invocation with unchanged source. Typed engine/JSON decoder causes remain available, while the wrapper's string is static. `schema_reference_origin_test.go` proves missing-resource root/repeated/escaped/array/relative-scoped/transitive ref origins in both dialects. `schema_reference_fragment_test.go` adds local/remote fragment/anchor, transitive resource, scoped ID, referenced extension subtree, URI-escaped physical source paths, mixed failures and dynamicRef/dialect evidence. Repeated runs prove deterministic public positions despite private placeholder identity. Annotation/default/example and unreachable definition candidates are excluded by the final root-reachable engine graph; candidate JSON fields do not themselves establish origins. False-schema probes never become validators or mapper/provider inputs and original source/resources/cause remain unchanged. HTTP fixtures cover both output/tool roles and transitive missing fragment/anchor with zero requests/mapper calls. Malformed JSON still has unknown position instead of a fabricated root; its assertions remain. Two malformed explicit resources repeatedly produce the sorted-first registration failure. No independent schema validator/URI resolver or error-string parser is introduced. Parent checkpoint evidence requires both final independent audits.

## Error and document boundaries

Final original validation uses `ErrSchemaJSONDecode` for invalid/truncated/multiple JSON documents, retaining decoder causes, and `ErrSchemaMismatch` for valid JSON violating constraints. Checked sync/buffered/native retain known provider result/diagnostics and fail without replay; capture uses safe `parse` classification. The one-shot structured helper does not turn invalid JSON into ordinary repairable `ValidationError`. Incremental parser failures use `ErrStructuredStream`, preserving typed causes where available. Domain validation remains post-schema/post-decode.

`schema_decode_error_test.go` and its adapter counterpart cover these boundaries. `provider_outcome_conformance_test.go` uses actual SDK parsers for refusal/incomplete before universal structured helpers, while OpenAI `refusal_schema_test.go` uses actual SDK SSE plus original validation and trailing usage. Whole-array constraints and invalid separators are verified by `schema_validation_test.go`, `structured_stream_lifecycle_test.go` and `task37_regression_test.go`: yielded items stay provisional and cannot hide failed document/terminal validation.

Reference-origin fixtures are implementation evidence, not final acceptance. IA08/09 corrections are independently confirmed in checkpoint7. Current parent IA07 correction uses actual-edge worklist discovery, compiler-only abort observations and stable target metadata instead of repeated whole-root probes. Permanent both-dialect cache/origin/zero-HTTP tests, 1,000-edge local/remote/mixed/annotation cases and explicit resources with Boolean/transitive targets pass; benchmarks include 10,000 edges and valid-engine baselines. Engine compilation itself remains input-dependent; no universal time bound or live endpoint parity claimed. Full gates and both independent reruns are required for changed source; the separate forced-tool-output conditional decision remains open.
