## Самостоятельная повторная проверка findings

Все три ранее написанных auditor probes перенесены без изменения из own r3 copy:

- Gemini mixed exact integer + unrelated float/source mismatch: signed/unsigned обе формы отвергаются `ErrProviderState`; rounding разрешён только соответствующему leaf, не целому object.
- Ollama поздний malformed arguments frame после reasoning/text/valid call: три части сохраняются, Outcome unknown, ContinuationUnavailable=true.
- Ollama поздний malformed **whole** JSON `{"message":` после того же prefix: теперь error и тот же retained prefix с **ContinuationUnavailable=true**. R3 blocker независимо закрыт на actual HTTP; AssistantMessage сохраняет marker, checked execution отвергает unavailable history.

Targeted actual fixtures `TestNativeEventFailureRetainsKnownParts` проверяют text, signed reasoning, exact completed call перед unsupported FunctionResponse в одном Gemini SSE событии. Prefix identities/state annotations корректны; unknown finish/outcome, unavailable=true, checked follow-up не dispatch (HTTP count1). `TestNativeSourceFailureRevokesEarlierExchange` проверяет missing finish/invalid late candidate. Existing actual Ollama transport/truncated EOF/error fixtures теперь также проверяют unavailable flag; root tests проверяют consumer stop и visibility before capture terminal observation.

Код universal closeout: `stream.go` observeCapture отзывает continuation до observer, complete отзывает при любом failed/canceled terminal state. Retained content и provider-known finish metadata не переписываются. Дополнение provider-neutral: нет SDK types, retry, fabricated result/finish или host loop. Gemini stream.go возвращает parsed prefix при parseErr, отбрасывает associations rejected parts, затем возвращает исходную ошибку. Signed binding и original schema validation не обходятся.
